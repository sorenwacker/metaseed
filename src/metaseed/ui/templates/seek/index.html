Export to FAIRDOM-SEEK

Export the current dataset as ISA RDF that SEEK ingests through its own built-in Import from FAIR Data Station feature — building the Investigation → Study → Assay/Sample structure and its Extended Metadata. No external tool is involved; metaseed generates the RDF directly.

Download SEEK ISA RDF (.ttl) →

Then, in SEEK

  1. Enable the feature (admin, once): Server administration → Enable/disable features → FAIR Data Station import.
  2. Open your Project → Import from FAIR Data Station.
  3. Upload the downloaded .ttl and submit.

Note: SEEK reads the ISA levels positionally, so with the ISA profile (no ObservationUnit level) entities below Study currently import one level high; Investigation and Study round-trip cleanly.
